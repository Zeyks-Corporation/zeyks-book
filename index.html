Accounting software for Nepal, built around the Bikram Sambat calendar

Zeyks Book is web-based double-entry bookkeeping for Nepali businesses. Record sales, purchases, expenses and settlements in NPR, work with Bikram Sambat and Gregorian dates, and print A4 financial reports.

Explore the features before you sign up

Try sample books in the interactive demo. Zeyks Book costs NPR 999 per month. Business records are stored in a managed cloud database, and a downloadable JSON backup is available from Settings. Backup restore is not available yet.

Review pricing and common questions, data storage and privacy, or contact Zeyks Book before moving real records.
